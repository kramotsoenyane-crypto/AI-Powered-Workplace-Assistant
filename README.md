# AI-Powered Workplace Productivity Assistant

> **Work Smarter. Write Faster. Plan Better.**

An AI-powered workplace productivity assistant designed to help users automate and improve common workplace tasks.

## Project Overview

This project was developed as part of the **AI Skills Acceleration Programme (ASA 19)**. It demonstrates practical Artificial Intelligence, prompt engineering, AI-assisted development, and responsible AI.

## Key Features

* **Email Generator** — Creates professional emails from purpose, context, key points, tone, and length.
* **Meeting Summarizer** — Converts meeting notes or transcripts into summaries, decisions, action items, responsible persons, deadlines, and follow-up questions.
* **Task Planner** — Breaks larger goals into actionable tasks with priorities, estimated time, deadlines, status, and progress.
* **Research Assistant** — Organises research into summaries, findings, concepts, advantages/disadvantages, applications, and references.
* **AI Chatbot** — Provides conversational workplace assistance for planning, writing, summarising, organising, and explaining topics.

> **Note:** AI-generated research should be verified against reliable sources before being used for important decisions.

## Prompt Engineering

The project uses the following prompt structure:

**Role + Context + Task + Constraints + Output Format**

Clear, contextual prompts help produce more consistent and useful AI outputs.

## Responsible & Ethical AI

The project considers:

* **Human Oversight** — Review AI output before professional use.
* **Privacy** — Protect confidential and sensitive information.
* **Accuracy** — AI can produce incorrect information.
* **Bias** — Critically review AI outputs for potential bias.
* **Security** — Never expose API keys or sensitive credentials in frontend code or GitHub.

## Demo Mode

The application can demonstrate core workflows when a live AI API is unavailable, including example email generation, meeting summaries, task plans, research responses, and chatbot conversations.

Future live AI integrations should use secure environment variables for credentials.

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/ai-workplace-productivity-assistant.git
cd ai-workplace-productivity-assistant
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm run dev
```

Open the local development URL shown in the terminal.
